## Order Tracking

Monitor your order status in real-time from preparation to delivery. Our GPS tracking shows the driver's location and estimated arrival time.

<CodeGroup tabs="iOS,Android">
  ```swift
  // iOS order tracking
  orderManager.trackOrder(orderId: "12345") { status in
      switch status {
      case .preparing:
          updateUI(with: "Restaurant is preparing your food")
      case .ready:
          updateUI(with: "Order ready for pickup")
      case .outForDelivery:
          updateUI(with: "Driver is on the way")
      case .delivered:
          updateUI(with: "Enjoy your meal!")
      }
  }
  ```
  ```kotlin
  // Android order tracking
  orderManager.trackOrder("12345")
      .observe(this) { status ->
          when (status) {
              OrderStatus.PREPARING -> updateUI("Restaurant is preparing your food")
              OrderStatus.READY -> updateUI("Order ready for pickup")
              OrderStatus.OUT_FOR_DELIVERY -> updateUI("Driver is on the way")
              OrderStatus.DELIVERED -> updateUI("Enjoy your meal!")
          }
      }
  ```
</CodeGroup>
