## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Introduced real-time delivery tracking with driver location sharing
- Added support for multiple payment methods including digital wallets
- Implemented restaurant rating and review system
- Launched promotional discount codes for first-time users

## Improvements

- Enhanced app performance with faster load times
- Improved search functionality with cuisine filters
- Updated user interface for better navigation
- Added push notifications for order status updates

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete app redesign with modern user interface
- Introduced restaurant partner dashboard for order management
- Added biometric authentication support
- Implemented order history and reordering functionality

## Breaking Changes

- Updated API endpoints for improved security
- Changed authentication flow to require email verification
- Modified order placement process with new validation steps

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Introduced customer loyalty program with points system
- Launched referral program for user acquisition
- Added dietary restriction filters for menu browsing

## Bug Fixes

- Fixed issue with order total calculations
- Resolved payment processing errors for certain card types
- Corrected delivery time estimates for remote locations
