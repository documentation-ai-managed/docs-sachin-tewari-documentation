## Restaurant Dashboard

Partner restaurants access a comprehensive dashboard to manage orders, update menus, and track performance metrics.

<CodeGroup tabs="Web,Mobile">
  ```javascript
  // Restaurant dashboard API example
  const dashboard = new RestaurantDashboard(apiKey);
  
  // Get current orders
  dashboard.getOrders().then(orders => {
      orders.forEach(order => {
          console.log(`Order ${order.id}: ${order.status}`);
      });
  });
  
  // Update menu item
  dashboard.updateMenuItem('pizza-margherita', {
      price: 14.99,
      available: true
  });
  ```
  ```kotlin
  // Mobile dashboard example
  val dashboard = RestaurantDashboard(apiKey)
  
  // Get current orders
  dashboard.getOrders().observe(this) { orders ->
      orders.forEach { order ->
          Log.d("Order", "${order.id}: ${order.status}")
      }
  }
  
  // Update menu item
  dashboard.updateMenuItem("pizza-margherita", 
      MenuItem(price = 14.99, available = true)
  )
  ```
</CodeGroup>
